# Galaxy Chat: концепция

## Что это

Веб-чат для друзей, где вместо списка чатов используются "планеты" в 3D-космосе. Каждая планета это отдельная комната с перепиской.

## Зачем нужно

Обычные мессенджеры скучные. Здесь пользователь не "создаёт группу", а "создаёт планету" и приглашает туда друзей. Общение становится атмосферным, хотя по сути остаётся обычным текстовым чатом.

## Как устроено

Приложение открывается в браузере на компьютере. Внутри только текст: никаких постов для всего мира, только сообщения друг другу. Пользователь создаёт планету, делится ссылкой-приглашением, друзья присоединяются, и общение идёт в реальном времени.

## Связь с проектом

Космос это главная идея, которая задаёт всё:

- **Интерфейс:** 3D-планеты вместо папок с чатами.
- **Сценарий:** "создать планету" вместо "создать группу", "пригласить на планету" вместо "добавить в контакты".
- **Техническая часть:** под 3D-картинкой работает обычный обмен сообщениями. Космос это просто визуальная обёртка.
