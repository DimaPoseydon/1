# Концепция для Galaxy Chat

# * Что это и зачем нужно?

**Galaxy Chat** - это не скучный мессенджер в виде планет космоса для общения с друзьями.

# * Как устроено?
Суть простая: это обычный текстовый чат для друзей, но с визуализацией в виде 3D-космоса, чтобы общаться было не скучно, а атмосферно.
