## 1. Что за проект

`galaxy-chat` — веб-приложение для обмена сообщениями, в котором вместо обычных комнат используются «планеты»: пользователь создаёт свою планету и приглашает друзей в чат.

**Стек:** Node.js и Socket.io на сервере, React + TypeScript и Context API на клиенте, трёхмерные планеты и спрайты — на React Three Fiber. Проект разделен на две части: `galaxy-server` и `galaxy-client`, каждую нужно запускать отдельно.

## 2. Кто им пользуется

| Группа | Что ей нужно от документации |
| --- | --- |
| Обычный пользователь | Как зарегистрироваться, создать планету, пригласить друзей и общаться |
| Продвинутый пользователь | Как развернуть проект локально, настроить сервер и клиент, какие зависимости нужны |
| Разработчик | Структура репозитория (`galaxy-server` / `galaxy-client`), как устроены сокеты, контекст и 3D-сцена |

Основная аудитория — первая группа: приложение задумано как обычный чат, поэтому инструкции должны быть понятны человеку без опыта в разработке. При этом README сейчас написан скорее для второй группы — тех, кто запускает проект локально.
