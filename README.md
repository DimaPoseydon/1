## 1. Что за проект

`galaxy-chat` — веб-приложение для обмена сообщениями, в котором вместо обычных
комнат используются «планеты»: пользователь создаёт свою планету и приглашает
друзей в чат.

Стек: Node.js и Socket.io на сервере, React + TypeScript и Context API на клиенте,
трёхмерные планеты и спрайты — на React Three Fiber. Проект разделён на две части:
`galaxy-server` и `galaxy-client`, каждую нужно запускать отдельно.

## 2. Кто им пользуется

| Группа | Что ей нужно от документации |
|---|---|
| Обычный пользователь | Как зарегистрироваться, создать планету, пригласить друзей и общаться |
| Продвинутый пользователь | Как развернуть проект локально, настроить сервер и клиент, какие зависимости нужны |
| Разработчик | Структура репозитория (`galaxy-server` / `galaxy-client`), как устроены сокеты, контекст и 3D-сцена |

Основная аудитория — первая группа: приложение задумано как обычный чат, поэтому
инструкции должны быть понятны человеку без опыта в разработке. При этом README
сейчас написан скорее для второй группы — тех, кто запускает проект локально.

## 4. Чего не хватает

Вопросы, на которые в текущей документации ответа нет:

1. **Как пользоваться приложением.** Раздел Usage назван «self explanatory», но
   нигде не описано, как зарегистрироваться, создать планету, пригласить друга
   и отправлять сообщения. Для основной аудитории это ключевой пробел.
2. **Требования к окружению.** Не указаны версии Node.js и npm, хотя автор советует
   ставить npm через `nvm` - без этого часть пользователей не сможет запустить проект.
3. **Настройка перед запуском.** Не описано, нужны ли переменные окружения, порты,
   ключи для сокетов или базы данных; как клиент узнаёт адрес сервера.
4. **Развёртывание.** Есть только локальный запуск — нет информации о том, как
   выложить проект в интернет, чтобы им могли пользоваться друзья.
5. **Структура репозитория.** Не объяснено, за что отвечают `galaxy-server`
   и `galaxy-client` и как они связаны между собой.
