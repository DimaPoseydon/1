# Galaxy Chat

**Galaxy Chat** — это веб-приложение для обмена сообщениями, в котором вместо обычных комнат используются "планеты". Вы создаёте свою планету и приглашаете друзей в чат.

**Репозиторий:** [github.com/DimaPoseydon/1](https://github.com/DimaPoseydon/1)

## Возможности

* Создание собственной "планеты" — отдельной комнаты для общения
* Приглашение друзей в чат по ссылке или коду планеты
* Обмен сообщениями в реальном времени
* Интерактивные 3D-планеты и спрайты на React
* Аутентификация пользователей

## Стек технологий

* **Сервер:** Node.js, Socket.io, TypeScript
* **Клиент:** React, TypeScript, Context API, React Three Fiber
* **Структура:** Проект разделен на `galaxy-server` и `galaxy-client`

## Требования

Перед установкой убедитесь, что у вас есть:

* **Node.js** версии 16.x или выше (рекомендуется LTS)
* **npm** 8.x или выше (или **yarn** 1.22+)
* **Git**
* Современный браузер с поддержкой WebGL (Chrome, Firefox, Edge, Safari)
