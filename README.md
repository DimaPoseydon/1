# Galaxy Chat

Galaxy Chat — это веб-приложение для обмена сообщениями, в котором вместо обычных комнат используются "планеты". Вы создаёте свою планету и приглашаете друзей в чат.

**Репозиторий:** [github.com/DimaPoseydon/1](https://github.com/DimaPoseydon/1)

## Возможности

- Создание собственной "планеты" — отдельной комнаты для общения
- Приглашение друзей в чат по ссылке или коду планеты
- Обмен сообщениями в реальном времени
- Интерактивные 3D-планеты и спрайты на React
- Аутентификация пользователей

## Стек технологий

- **Сервер:** Node.js, Socket.io, TypeScript
- **Клиент:** React, TypeScript, Context API, React Three Fiber
- **Структура:** Проект разделен на `galaxy-server` и `galaxy-client`

## Требования

Перед установкой убедитесь, что у вас есть:

- Node.js версии **16.x или выше** (рекомендуется LTS)
- npm **8.x или выше** (или yarn 1.22+)
- Git
- Современный браузер с поддержкой WebGL (Chrome, Firefox, Edge, Safari)

Проверить версии:

```bash
node --version
npm --version
```

## Установка и запуск

Проект состоит из двух частей: `galaxy-server` (серверная часть) и `galaxy-client` (клиентская часть). Их нужно установить и запустить по отдельности.

### 1. Клонирование репозитория

```bash
git clone https://github.com/DimaPoseydon/1.git
cd 1
```

### 2. Запуск сервера

```bash
cd galaxy-server
npm install
npm run dev
```

Если вы используете yarn:

```bash
cd galaxy-server
yarn
yarn dev
```

### 3. Запуск клиента

В новом окне терминала:

```bash
cd galaxy-client
npm install
npm run dev
```

Или с yarn:

```bash
cd galaxy-client
yarn
yarn dev
```

После запуска клиент будет доступен по адресу, который выведет Vite (обычно `http://localhost:5173` или `http://localhost:3000`).

## Пример использования

1. Откройте приложение в браузере по адресу из шага 3.
2. Зарегистрируйтесь или войдите в существующий аккаунт.
3. На главном экране нажмите **"Создать планету"** и задайте ей имя.
4. Скопируйте ссылку-приглашение и отправьте её другу.
5. Когда друг присоединится к планете, начните переписку.
